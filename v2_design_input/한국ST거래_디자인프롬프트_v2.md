# 한국ST거래 디자인 프롬프트 — Google Stitch용 (v2 기준)

요청 번호는 이전 대화의 1~5번과 같고, 6번은 v2 구조 반영 화면입니다. 각 코드 블록이 Stitch에 넣는 프롬프트 1회분입니다.

---

## 0. 사용 순서

[Stitch 사용 순서]
1. 새 프로젝트에서 플랫폼을 'Mobile'로 선택합니다. 이미지 입력이 가능한 모드에서는 기존 캡처(Git images 폴더의 해당 번호 PNG)를 참고 이미지로 함께 올립니다.
2. 아래 'DESIGN.md' 블록을 프로젝트의 DESIGN.md(디자인 시스템)에 붙여 넣습니다. 지원되지 않으면 각 프롬프트 맨 앞에 붙입니다.
3. 프롬프트는 한 번에 화면 1~3개씩 입력합니다(Stitch는 여러 화면을 요청하면 목록 확인 후 생성하고, 한 번에 6개까지만 생성합니다).
4. 생성 후 화면을 선택해 '수정 프롬프트'로 다듬습니다. 여러 화면에 같은 수정을 적용할 때는 Shift로 다중 선택합니다.
5. 프롬프트의 화면ID(S###)는 엑셀 v2의 화면ID와 같습니다. 프레임 이름에 그대로 쓰면 기능정의와 맞추기 쉽습니다.
6. 프롬프트 안의 값은 예시 데이터입니다(기존 캡처의 샘플 값 사용).

---

## 0. DESIGN.md (공통)

```text
# 한국ST거래 Design System (v2)

## 플랫폼·톤
- Mobile app, 390×844, 라이트 모드 1종, 한국어(해요체). 신뢰감 있고 차분한 금융 앱, 전통 음식점 가게를 다루는 따뜻한 느낌은 일러스트·아이콘 톤으로만 살짝.

## 색 (기존 캡처에서 눈대로 가져온 근사값 — 원본과 대조해 보정)
- Primary: 진한 남색 #2E2A6B (주요 버튼, 선택된 탭·칩)
- 배경 #FFFFFF / 섹션 배경 #F5F5F7 / 카드 배경 #FAFAFA + 1px #E5E5EA
- 칩·비활성 버튼 배경: 연한 라벤더 #EFEFF6
- 강조 링크: 골드 #B8860B
- 상승·매수·구매: 빨강 #E5162B / 하락·매도·판매: 파랑 #2C6FE0 (한국 금융 관습)
- 텍스트 #1A1A1A, 보조 텍스트 #8A8A8E

## 형태
- 카드 라운드 16, 버튼 라운드 12, 칩·세그먼트 라운드 999. 8pt 간격. 터치 영역 최소 44px.
- 서체: Pretendard 계열 산세리프. 숫자는 굵게, 금액은 천 단위 쉼표+'원'.

## 컴포넌트 규칙 (모든 화면에서 동일하게)
- 2뎁스 탭: 언더라인 탭(활성=진한 텍스트+2px 남색 밑줄). 3뎁스 보기 전환: 세그먼트(회색 트랙 위 활성 항목만 흰 카드, 높이 36).
- 정렬(단일 선택)·단일 선택 필터: 트리거(정렬명+▾) 아래에 뜨는 작은 팝업 카드, 선택 항목에 체크, 탭 즉시 적용. 복수 섹션·복수 선택 필터·기간 선택: 바텀시트(핸들·타이틀·X·섹션별 칩·하단 [초기화][적용]).
- 드롭다운 select, 깔때기 아이콘으로 정렬을 여는 방식은 쓰지 않는다.
- 짧은 확인·요약은 바텀시트, 독립 콘텐츠·결과 화면은 전체 페이지(← 뒤로가기 + 제목), 예/아니오 확인은 중앙 다이얼로그. 우측 X로 닫는 오버레이 상세는 쓰지 않는다.
- 관심 표시는 하트(♡/♥)만. 북마크·스크랩 아이콘 금지.
- 계좌 표기는 '[증권사 로고] 한국ST거래증권 ····1234 ⌄' 단일 셀렉터 1종(라벨 칩·(?)·[계좌변경 >] 금지).
- 모든 목록 화면에 로딩(스켈레톤)·빈 상태·오류 상태를 함께 고려한다.

## 금지
- 새로운 색·아이콘 스타일 추가, 투자 권유·수익 보장으로 읽히는 문구, 이미지 생성.
```
