거래 / 전체 / 종목상세 / 주문 (간편)

초안 로그인 후

기능정의 7개

1

헤더 — 종목 요약 · 모드전환 · 찜

- 종목명(전주 리모델링 1호 (B증권)) · 현재가 5,000원 · 등락률 0.0% 축소 요약이 헤더 중앙에 표시 - 현재가는 5초 주기로 자동 갱신(숫자 굴림 애니메이션) - 우측 아이콘: 간편↔일반 모드 전환(막대 아이콘) · 찜(♡, 로그인 필요)

2

탭바

- 정보 / 주문 / 호가 / 차트 / 내주문 / 커뮤니티 6개 탭, 현재 화면은 "주문" 탭 선택 상태(밑줄 표시) - 내주문 탭만 로그인(+계좌연결) 필요, 나머지는 비로그인 열람 가능

3

구매/판매/대기 세그먼트

- 3분할 토글: 구매(빨강) / 판매(파랑) / 대기(미체결 목록) - 이 화면은 "구매" 선택 상태 - 색상은 한국 금융 관습(상승·매수=빨강, 하락·매도=파랑)을 따름

4

구매 희망가 입력

- "AI매칭" 텍스트 링크 + ⓘ 툴팁이 라벨 옆에 배치 — 누르면 AI매칭 모드(직접 가격 미지정)로 전환 - 값(5,000원)은 화면 진입 시 최신 시세로 자동 채워짐, +/- 버튼으로 조정 - 입력 중에는 시세가 갱신돼도 값이 바뀌지 않음(사용자 입력 보호)

지정가 주문만 가능하며 호가 단위는 자동 보정됨(제12조)

5

수량 입력

- 미입력 시 placeholder "몇개를 구매할까요?" 표시 - 하단에 "주문가능 {금액}원 · 최대 {개수}개 ⓘ" 안내 — 예수금 중 잠기지 않은 가용 금액 기준으로 추정

6

숫자 키패드

- 1~9 · 0 · 초기화(전체 삭제) · 삭제(⌫) 로 수량 입력 - 가격은 이 키패드가 아닌 희망가 필드의 +/- 버튼으로만 조정

7

하단 CTA — 호가 / 구매하기

- [호가]: 호가창으로 진입(가격 참고·선택) - [구매하기]: 수량 미입력 시 옅은 색으로 비활성 표시, 입력 완료 시 진한 빨강으로 활성화 - 누르면 거래시간→로그인→계좌연결→거래정지→투자성향→소득적격→틱보정→한도 순 게이트를 지나 확인 팝업으로 이동
