거래 /보유/계좌변경

거래 / 보유 / 계좌 요약> 계좌변경

초안

기능정의 5개

1

헤더 — 닫기(X) · '기본 거래 계좌 설정'

- 우상단 X로 바텀시트를 닫는다 - 안내문: '주문은 기본 계좌로만 가능해요. 다른 계좌로 거래하려면 기본 계좌를 변경해주세요.' / '기본 계좌는 이 기기에서만 기억해요.'

이용약관 제6조 2항: 구매·판매 주문은 기본 거래 계좌로 설정한 계좌로만 가능하며, 기본 거래 계좌 변경은 마이페이지 또는 거래 화면에서 언제든지 가능하다.

2

현재 기본 계좌 카드 (한국ST거래증권)

- 체크 표시(파란 테두리)로 현재 선택된 기본 계좌를 표시 - 계좌번호는 마스킹(TEST****O...)되어 노출 - [변경] 버튼으로 다른 연결 계좌로 기본 계좌 전환 가능

3

거래 계좌 추가 섹션 안내

- '계좌를 추가하고 기본 계좌로 설정하면 바로 거래할 수 있어요' 문구로 미연결 증권사 추가를 유도

4

미연결 증권사 카드 — 백년증권/KRST증권

- 증권사별 카드에 [필수] 연계정보(CI) 수집·이용 및 제3자 제공 동의 체크박스(펼침 화살표로 상세 약관 확인 가능) - 동의 체크 전에는 [계좌 연결 하기] 버튼이 비활성(회색)으로 보인다 - 동의 후 버튼을 누르면 해당 증권사 계좌 연결 플로우로 이동

이용약관 제6조 1·3항: 여러 증권사 계좌를 동시에 연동할 수 있으며, 플랫폼과 증권사는 회원의 개인식별번호(CI)를 기준으로 동일인 여부를 확인하고 계좌 정보를 암호화하여 주고받는다.

5

하단 [완료] 버튼

- 계좌 선택/추가를 마치고 바텀시트를 닫는 확정 버튼
