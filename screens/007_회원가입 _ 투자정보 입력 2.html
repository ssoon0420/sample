회원가입 / 투자정보 입력 2

편집중

기능정의 11개

1

뒤로가기 버튼

- 화면 좌측 상단의 화살표 아이콘 - 클릭 시 이전 단계(투자정보 입력 1)로 돌아감 - 입력 중이던 내용은 저장되지 않을 수 있음(별도 확인 팝업 여부는 미확인)

2

진행 단계 표시 (03/03)

- 회원가입 내 투자정보 입력 절차의 마지막 단계(3단계 중 3단계)임을 나타내는 텍스트 및 진행 바 - 사용자 조작 요소 아님, 단순 안내용 UI

3

화면 타이틀

- "투자를 위한 기본정보를 입력해주세요." 안내 문구 - 본 화면이 투자 목적의 기본정보(주소, 국적, 자금출처, 투자목적, 직업)를 수집하는 단계임을 명시

4

주소검색 버튼

- '자택 주소' 라벨 옆에 위치한 보조 버튼 - 클릭 시 우편번호/주소 검색 레이어(다음/카카오 우편번호 서비스 등으로 추정)가 열려 주소를 검색·선택할 수 있음 - 선택 시 하단 주소 표시 필드에 우편번호 및 도로명주소가 자동 입력되는 것으로 추정 - 필수 입력 항목으로 보이며 미입력 시 하단 '확인' 버튼 제출이 제한될 수 있음(추정)

5

자택 주소 표시 필드

- 주소검색을 통해 선택된 우편번호 및 도로명주소를 표시하는 읽기전용(비활성) 입력창으로 보임 - 예시: "[07326] 서울 영등포구 국제금융로 10" - 직접 타이핑이 아닌 주소검색 버튼을 통해서만 값이 채워지는 구조로 추정

6

상세주소 입력창

- 도로명주소 하단의 상세주소(건물명, 동/호수 등) 입력 필드 - 현재 "여의"라는 텍스트가 입력 중인 상태로 캡처됨 - 자유 텍스트 입력, 최대 글자수 등 유효성 제약은 화면상 확인 불가

7

국적 선택 필드 (필수)

- 라벨 '국적' 옆 빨간 별표(*)로 필수 입력 항목임을 표시 - 현재 값 "내국인 (대한민국)"으로 기본 선택되어 있음 - 클릭 시 국적 선택 목록(내국인/외국인 등)이 열리는 선택형(select) 필드로 추정 - 약관상 만 19세 이상 국내 회원만 이용 가능하다는 가입 자격과 연계된 항목으로 추정

만 19세 이상 국내 회원만 서비스 이용이 가능하며, 타인 정보 도용이나 허위 정보 제출 시 가입 거부 또는 이용계약 취소 대상이 될 수 있음(참고 약관 제4조)

8

자금출처 선택 필드 (필수)

- 라벨 '자금출처' 옆 빨간 별표(*)로 필수 입력 항목임을 표시 - 현재 값 "근로소득(급여)"으로 기본 선택되어 있음 - 클릭 시 자금출처 선택 목록(근로소득, 사업소득, 금융소득 등)이 열리는 선택형 필드로 추정 - 자본시장법상 투자자 정보 확인 절차의 일부로 보이며, 이후 투자자 성향 분석 및 소득적격회원 심사와 연계될 가능성 있음(추정)

9

투자목적 선택 필드 (필수)

- 라벨 '투자목적' 옆 빨간 별표(*)로 필수 입력 항목임을 표시 - 현재 값 "저축 및 투자"로 기본 선택되어 있음 - 클릭 시 투자목적 선택 목록이 열리는 선택형 필드로 추정

10

직업 선택 필드 (필수)

- 라벨 '직업' 옆 빨간 별표(*)로 필수 입력 항목임을 표시 - 현재 값 "직장인(회사원)"으로 기본 선택되어 있음 - 클릭 시 직업 선택 목록이 열리는 선택형 필드로 추정

11

확인 버튼

- 화면 하단 전체 폭의 진한 남색 버튼, 텍스트 "확인" - 클릭 시 입력된 기본정보(주소, 국적, 자금출처, 투자목적, 직업)를 제출하고 다음 단계(회원가입 완료 또는 본인인증 등)로 이동하는 것으로 추정 - 필수 항목(국적, 자금출처, 투자목적, 직업 및 주소)이 모두 입력되지 않으면 비활성화되거나 제출 시 오류 안내가 표시될 것으로 추정 - 진행 단계 표시가 03/03이므로 이 단계가 투자정보 입력의 마지막이며, 제출 후 회원가입 절차가 완료되거나 다음 절차(계좌 연동 등)로 넘어갈 가능성이 있음(추정)
