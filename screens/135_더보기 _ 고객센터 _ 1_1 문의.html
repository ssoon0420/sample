더보기 / 고객센터 / 1:1 문의

더보기 / 고객센터 / 1:1 문의 / 내 문의내역

초안

기능정의 5개

1

문의유형 선택 · 제목 프리필

- 상단 드롭다운(공통코드 문의유형) 중 하나를 반드시 선택 — 현재 '상장 제안' 선택 상태 - 내 주변 지도의 비상장 가게 [상장 제안] 버튼으로 진입하면 유형이 '상장 제안'으로, 제목이 `[{가게명}] 상장 제안`으로, 본문이 안내 문구로 자동 프리필된다(이 화면의 예시 내용이 그 경우)

2

제목·본문 입력 및 글자수 제한

- 제목 최대 20자, 본문 최대 10,000자 — 초과분은 입력 자체가 막히며 `n/10,000자` 카운터로 실시간 표시 - 문의유형·제목·본문 모두 필수 입력이며 미입력 시 [문의하기] 진행 불가

3

첨부파일

- 최대 10개 · 개당 5MB · JPG/PNG/WEBP만 실제 첨부 가능(카메라 촬영 포함) - 안내 문구는 '사진 및 파일(PDF)…'로 PDF를 언급하지만 실제로는 PDF 첨부가 불가능한 문구-정책 불일치 상태 - Android 기기의 카메라 촬영본은 네이티브 이슈로 첨부되지 않는 문제가 있음(갤러리 선택은 정상, iOS는 정상)

4

개인정보 처리 안내

- 탭하면 1:1 문의 전용 개인정보 처리 안내 시트가 열린다([확인했어요] 버튼의 별도 팝업 화면) - 동의 체크박스가 아니라 열람 전용이며, 확인 여부가 [문의하기] 제출 조건에 영향을 주지 않는다

5

문의하기 버튼

- 첨부파일 업로드 → 문의 접수 순서로 처리되며, 업로드가 실패하면 접수를 시도하지 않고 별도의 업로드 실패 안내(재첨부 필요)가 뜬다 - 접수 성공 시 토스트 `문의가 접수되었습니다.` 후 문의 내역·MY 활동내역의 문의 건수가 즉시 갱신된다 - 문의 내역의 [수정] 경유 시 이 화면이 수정 모드로 재사용되어 기존 제목·본문·첨부가 미리 채워지고, 완료 시 `문의가 수정되었습니다.` 토스트가 뜬다
