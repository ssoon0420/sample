로그인

로그인 / 로그인

초안 로그인 후

기능정의 7개

1

안내 타이틀

"로그인하면 / 더 많은 기능을 이용할 수 있어요." 2줄 안내 문구 - 비로그인 상태로도 종목·가게 탐색, 공시, 공지 열람 등은 가능하지만 주문·찜·보유·알림·MY 등 개인화 기능은 로그인 후에만 쓸 수 있음을 안내한다

2

아이디 입력

- 텍스트 입력 필드. 값이 없으면 플레이스홀더가 보이고, 캡처에는 예시 아이디 'sto-test-10'이 입력된 상태 - 존재하지 않는 아이디이거나 형식이 틀리면 필드 아래 인라인 오류 문구(예: "아이디를 다시 확인해주세요.")가 노출된다

3

비밀번호 입력

- 마스킹(●●●) 처리된 텍스트 입력 필드 + 우측 눈 모양 아이콘으로 평문/마스킹 토글 - 값 미입력 또는 서버 인증 실패(아이디/비밀번호 불일치 등) 시 필드 아래 인라인 오류 문구로 사유를 안내한다

4

서명 로그인 · 아이디 저장

- '서명 로그인' 체크박스: 전자서명 기반 로그인 여부를 선택하는 옵션으로 보이며, 상세 동작은 이 캡처만으로는 확정할 수 없다 - '아이디 저장' 체크박스: 체크 후 로그인하면 다음 접속부터 아이디 입력칸에 값이 자동으로 채워진다

5

계정 찾기 · 회원가입

- '아이디 찾기', '비밀번호 찾기' 텍스트 링크 — 각각 계정 복구 플로우로 이동(본 캡처 범위 밖) - '회원가입' 링크 — 신규 이용자가 이미 작성된 회원가입/약관 동의 플로우로 진입하는 경로

6

다른 방법으로 로그인

- 탭하면 현재 화면이 딤 처리되며 화면 하단에서 로그인 방법 선택 바텀시트가 올라온다 - 바텀시트에는 '간편 인증으로 로그인', '생체 인증으로 로그인' 두 옵션이 있어 아이디/비밀번호 입력 없이 로그인할 수 있는 대체 경로를 제공한다(다음 화면 참고)

이용약관 제5조① 로그인 방법은 아이디/비밀번호, 간편 비밀번호(PIN), 생체인증(지문·안면) 세 가지로 정의되어 있다.

7

로그인 버튼

- 아이디·비밀번호 입력 후 탭하면 인증을 요청한다 - 성공 시 세션이 발급되고 로그인 전 화면 또는 홈으로 이동 - 실패 시 인라인 오류(아이디/비밀번호 문구) 또는 네트워크 오류 시 하단 토스트 "일시적인 오류가 발생했어요. 잠시 후 다시 시도해주세요."가 뜬다

이용약관 제5조③ 로그인은 1개 기기에서만 가능하며, 다른 기기에서 로그인하면 이전 기기의 로그인은 자동으로 해제된다. 제5조⑤ 로그인 정보 관리 책임은 회원 본인에게 있으며 타인 공유로 인한 손해는 회사가 책임지지 않는다.
