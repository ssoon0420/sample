MY / 활동 내역 / 커뮤니티

초안

기능정의 4개

1

상단 탭바 — 활동 내역 / 내 정보 / 내 투자성향

- MY 메인 하위 3탭 중 '활동 내역' 선택 상태(밑줄) - '내 정보' 탭 이동 시 별도 재인증 게이트가 뜬다(마지막 로그인 방식에 따라 비밀번호/간편인증/생체, 유효 5분, 탭 이동만으로 즉시 초기화) - 우측 상단 ⚙ 설정, 🔔 알림(안읽음 배지 있으면 표시)

2

커뮤니티 / 문의내역 세그먼트

- 이 화면은 MY 메인의 '활동 내역' 카드를 눌러야 정상 진입(?tab=community 쿼리 포함) - 쿼리 없이 /my/activity 로 직접 진입하면 탭 어디에도 없는 '방문내역' 빈 화면이 뜨는 알려진 제약이 있다 - 커뮤니티: 내가 쓴 글(게시글·댓글) / 문의내역: 1:1 문의 내역

3

게시글·댓글 구분 + 정렬 필터

- 총 N건은 서버 집계 총건수 - 좌측 드롭다운으로 게시글/댓글 전환(게시글+댓글 통합 보기는 없음) - 우측 [필터]는 정렬 전용 — 게시글: 최신순·좋아요 많은순·댓글 많은순 / 댓글: 최신순·좋아요 많은순(댓글 많은순 없음), 기본 최신순 - 정렬을 바꾸면 목록이 처음부터 다시 로드된다

4

빈 상태 — 작성한 게시글이 없어요.

- 게시글 탭에 작성 이력이 없을 때 아이콘 + 안내 문구 - 댓글 탭의 빈 상태 문구는 '작성한 댓글이 없어요.' - 목록은 20건 단위 로드 + [더보기] 버튼 방식(무한 스크롤 아님)
