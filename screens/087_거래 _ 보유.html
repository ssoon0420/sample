거래 / 보유

편집중 로그인 후

기능정의 17개

1

[현재가|평가금] 표시 전환 드롭다운

- 좌측 '현재가 v'를 누르면 행의 금액 표시를 현재가 ↔ 평가금(현재가×보유수량)으로 전환한다 - 평가금 모드에서는 등락 금액·등락률이 내 평균단가 대비로 바뀐다 - 선택은 앱을 쓰는 동안 기억되며(탭 이동해도 유지), 새로고침·재시작 시 현재가로 복귀

2

정렬 — '평가금 높은순' + 필터

- 보유 탭 전용 정렬 3종: 평가금 높은순(기본)·현재가 높은순·가나다순 — 오름차순 선택지 없음(가나다순만 예외) - 필터 아이콘은 부가 필터 시트 진입 - 정렬 변경 시 목록이 처음부터 다시 그려진다(펼친 것은 접힘) - '평가금 높은순'은 보유수량 × 현재가(서버 산정) 기준으로 정렬한다(참고: 30-trade-list.md)

3

보유 종목 카드 — 종목명/가게명/개당단가·수량/현재가·등락

- 카드에 보유수량과 내 평균단가(수수료 미포함)가 함께 표시 - 우측에 현재가(또는 평가금)와 등락(▲빨강/▼파랑) - 카드를 탭하면 종목 상세로 이동(상장폐지 종목 제외)

이용약관 제14조 2항: 수익률과 평가금액은 소수점 이하를 절삭하여 표시되므로 실제 정산 금액과 차이가 발생할 수 있다.

4

상장폐지 보유 종목 처리

- 상장폐지 종목(listing_status=D)은 가격 자리에 '-', 그 아래 '상장폐지' 라벨 - 행이 비활성화되어 눌러도 종목 상세로 진입하지 않는다 — 공시·분배 이력을 확인할 경로가 없다(알려진 제약)

5

보유 0건 / 계좌 미연결 상태

- 보유 종목이 없으면 '보유 종목이 없어요.' 안내 - 증권계좌 미연결 회원은 이 목록 대신 '투자, 이제 시작만 남았어요.' + [계좌 연결하기] 전체화면 안내로 대체된다

6

거래 하위 탭 (전체/보유/관심)

- 3개 탭으로 구성된 세그먼트 메뉴이며 현재 '보유' 탭이 선택된 상태 - '전체' 탭: 보유 종목과 관심 종목을 함께 노출 - '보유' 탭: 현재 화면으로, 실제 보유 중인 종목만 노출 - '관심' 탭: 찜(관심등록)한 종목만 노출 - 각 탭 전환 시 하단 목록만 갱신되고 상단 계좌 요약 카드는 유지되는 것으로 추정 - 로그인 및 증권사 계좌 연결이 되어 있지 않으면 탭 진입 시 안내/유도 화면이 뜰 수 있음

7

프로필/계정 아이콘

- 원형 아바타 버튼으로, 탭 시 마이페이지 또는 계정 관련 메뉴로 이동하는 동적 동작으로 추정 - href 정보가 감지되지 않아 정확한 이동 경로는 미상 - 로그인 상태를 시각적으로 표시하는 역할도 겸하는 것으로 보임

8

알림 버튼

- 종 모양 아이콘 버튼으로, 탭 시 알림함(체결 알림, 주문 만료 안내, 자격 갱신 안내 등)으로 이동하는 동적 동작으로 추정 - 미확인 알림이 있을 경우 배지(뱃지)가 표시될 수 있음 (현재 화면에는 배지 미노출) - href 정보가 감지되지 않아 정확한 목적지는 미상

9

기본 거래 계좌 안내 (한국ST거래증권)

- 현재 설정된 기본 거래 계좌(연동 증권사명)를 표시하는 뱃지형 버튼 - 옆의 (?) 아이콘 탭 시 '기본 거래 계좌' 용어에 대한 툴팁/설명 팝업이 뜨는 것으로 추정 - 구매·판매 주문은 이 기본 거래 계좌로만 제출 가능 - 여러 증권사 계좌를 연동한 경우에도 화면에는 기본 계좌 1개만 표시됨

기본 거래 계좌는 마이페이지 또는 거래 화면에서 언제든지 변경할 수 있다.

10

계좌변경 버튼

- 우측 상단의 '계좌변경 >' 버튼으로, 탭 시 연동된 증권사 계좌 목록 중 기본 거래 계좌를 변경하는 화면/팝업으로 이동하는 동적 동작으로 추정 - 변경 즉시 상단 카드의 평가금·계좌잔고·보유 목록이 새 계좌 기준으로 갱신될 것으로 예상 - 연동된 계좌가 1개뿐인 경우 변경 옵션이 비활성화되거나 안내 문구가 뜰 수 있음 (미확인)

11

나의 평가금 / 계좌잔고 (주문 대기 금액 포함)

- '나의 평가금': 보유 종목의 현재가 기준 평가금액 합계와 손익(금액·수익률)을 표시 - 수익률·평가금액은 플랫폼의 자체 이동평균법(평균 매입단가) 기준 참고 수치로, 소수점 이하 절삭 표시되어 실제 정산 금액과 차이가 발생할 수 있음 - '계좌잔고' 옆 화살표(⌄) 탭 시 상세 내역이 펼쳐지며, 이때 '주문 대기 금액'(미체결 주문으로 잠긴 금액)과 실제 주문가능금액이 구분 표시되는 동적 동작으로 추정 - 미체결 구매 주문이 있으면 해당 주문 금액+수수료만큼 잔고가 잠금(Lock) 처리되어 주문가능금액에서 제외됨

수익률과 평가금액은 참고용이며 실제 손익과 다를 수 있다. 세금 계산 및 원천징수는 증권사에서 처리한다.

12

주문내역 버튼

- 탭 시 주문/체결 내역 조회 화면(내주문 탭 등)으로 이동 - 미체결, 부분체결, 체결완료, 주문취소 등 상태별 주문 목록을 확인 가능 - 실 API 기반이며 약 5초마다 자동 갱신되는 화면으로 연결되는 것으로 추정 - 로그인 및 계좌 연결이 되어 있지 않으면 접근 시 안내 토스트가 노출될 수 있음

13

나의 수익 버튼

- 탭 시 전체 보유 종목의 누적 수익률/손익 현황을 모아 보는 화면으로 이동하는 동적 동작으로 추정 - 표시되는 수익률은 이동평균법(평균 매입단가) 기준 플랫폼 자체 계산값으로 실제 증권사 정산 금액과 차이가 있을 수 있음 - href 정보가 감지되지 않아 정확한 목적지는 미상

수익률·평가금액은 참고용 수치이며, 판매 수익 및 분배소득에 대한 세금은 증권사 정책에 따라 처리된다.

14

거래 한도 버튼

- 탭 시 현재 회원 등급(일반회원/소득적격회원) 기준의 보유 한도, 연간거래 한도, 1일 회전율 사용 현황을 보여주는 화면으로 이동하는 동적 동작으로 추정 - 한도 초과 시 신규 주문이 시스템에서 자동 거부됨을 안내하는 내용이 포함될 것으로 예상

보유 한도: 일반회원 1,000만 원 / 소득적격회원 3,000만 원. 연간거래 한도: 일반회원 4,000만 원 / 소득적격회원 8,000만 원. 1일 회전율: 등급 무관 100% 이하 (초과 시 다음 영업일부터 거래 가능).

15

필터 및 정렬 (현재가/평가금)

- '필터' 버튼: 탭 시 보유 종목 목록을 좁히는 조건(예: 가게별, 종목별 등)을 선택하는 바텀시트가 뜨는 동적 동작으로 추정 - '현재가'/'평가금' 토글: 목록 우측에 표시되는 금액 기준을 현재가 또는 평가금(보유수량×현재가 등) 중 선택하여 전환 - 상단의 '평가금 높은순'은 현재 목록 정렬 기준을 나타내는 표시로, 별도 탭 시 정렬 옵션 변경 가능성 있음 (동적 동작 추정) - 총 9건: 현재 필터/정렬 조건에 해당하는 보유 종목 총 개수

16

보유 종목 리스트 (종목 카드)

- 보유 중인 종목을 카드 형태로 나열: 가게명/종목명, 개당 평균단가 및 보유수량, 우측에 현재가와 전일대비 등락률(%) 표시 - 카드 탭 시 해당 종목의 상세 화면(정보/호가/차트/내주문 탭 구성)으로 이동하는 동적 동작으로 추정 — 상세 화면 URL은 `/trade/{종목ID}` 형태로 유추됨 - 등락률 0.0%는 당일 체결 내역이 없어 전일 마지막 체결가와 동일함을 의미 - 예: '노을다반 서귀포 리모델링 1호' 개당 4,888원/120개 보유, 현재가 5,700원(0.0%) - 예: '고요한상 안동 리모델링 1호' 개당 4,500원/1개 보유, 현재가 600,000원(0.0%) - 최대 200건까지 표시되며 그 이상은 스크롤/더보기로 추가 노출되는 구조로 추정

현재가는 가장 마지막에 체결된 가격이며, 오늘 거래가 없으면 어제(또는 최근 거래일) 마지막 체결가가 표시된다.

17

하단 탭 내비게이션

- 홈(집 아이콘): 탭 시 홈 화면(/home)으로 이동 - 백년가게(가게 아이콘): 탭 시 백년가게/가게 목록 화면(/stores)으로 이동 — 지도 기반 '내 주변' 탐색 등을 포함 - 거래(막대그래프 아이콘, 현재 선택됨): 탭 시 거래 화면(/trade)으로 이동 — 현재 표시 중인 화면 - MY(사람 아이콘): 탭 시 마이페이지(/my)로 이동, 계좌 관리/차단 관리 등 포함 - 더보기(점 3개 아이콘): 탭 시 더보기 메뉴(/more)로 이동 - 각 항목은 로그인 여부와 무관하게 노출되나, 거래·MY 등 일부 기능은 진입 후 로그인/계좌 연결이 요구될 수 있음
