회원가입 / 로그인설정 (생체)

편집중

기능정의 6개

1

간편 인증으로 로그인 설정 카드

- PIN 아이콘(****)과 '간편 인증으로 로그인' 텍스트가 표시된 선택형 카드 - 회원가입/로그인설정(생체) 화면 문맥상 간편 비밀번호(PIN) 또는 생체인증(지문·안면) 등록을 시작하는 진입 요소로 추정됨(화면에서 감지된 링크/버튼 목록이 제공되지 않아 실제 이동 대상은 스크린샷만으로 단정할 수 없음) - 탭 시 기기에 등록된 생체정보 인식 또는 PIN 입력 화면으로 이어지는 것으로 보이며, 설정 완료 후 하단 [확인] 버튼이 활성화될 가능성이 있음 - 카드가 선택/미선택 토글 형태인지, 탭 즉시 별도 화면으로 이동하는 링크형인지는 스크린샷만으로 확정할 수 없음

약관 제5조④에 따르면 간편인증(PIN·생체인증) 설정을 위해서는 별도의 본인인증 완료 후 신규 기기 등록 절차가 필요할 수 있음

2

안내 타이틀 문구

- '로그인, 더 쉽게 할 수 있어요.' / '간편 로그인 방식을 설정해주세요.' 2줄 굵은 텍스트 - 화면의 목적(간편 로그인 방식 설정)을 안내하는 순수 정보성 텍스트로, 클릭 동작 없음

3

확인 버튼

- 화면 하단 우측에 위치한 주요 액션 버튼 - 탭 시 위에서 설정한 간편 인증(생체인증/PIN) 방식을 저장하고 다음 화면(가입 완료 또는 로그인 흐름)으로 진행하는 것으로 추정됨 - 간편 인증 카드가 아직 설정되지 않은 초기 상태에서는 비활성(회색) 상태일 수 있으며, 설정 완료 시 활성화되는 형태로 보임(실제 활성화 조건은 스크린샷만으로 단정 불가) - 필수 항목 미입력/미설정 시 탭해도 진행되지 않고 안내 메시지가 표시될 가능성 있음

4

취소 버튼

- 화면 하단 좌측에 위치한 보조 액션 버튼 - 탭 시 간편 로그인 방식 설정을 취소하고 이전 화면(가입 절차 또는 로그인 화면)으로 돌아가는 것으로 추정됨 - 별도의 확인 팝업 없이 즉시 취소 처리되는지는 스크린샷만으로 확인 불가

5

뒤로가기 버튼

- 좌상단 화살표(←) 아이콘 - 탭 시 직전 화면(회원가입 절차의 이전 단계)으로 돌아가는 내비게이션 버튼으로 추정됨 - 입력/선택 중이던 간편 인증 설정 내용은 저장되지 않고 소실될 가능성 있음

6

간편 로그인 방식 변경 안내 문구

- '※ 로그인 방식은 마이 > 설정에서 언제든 바꿀 수 있어요.' 회색 보조 텍스트 - 현재 설정한 간편 로그인 방식이 이후 마이페이지 내 설정 메뉴에서 변경 가능함을 안내하는 정보성 텍스트 - 클릭 동작이 있는 링크형 텍스트인지, 단순 안내 문구인지는 스크린샷만으로 단정할 수 없음(밑줄 등 링크 스타일 없음 기준 단순 텍스트로 추정)

로그인 방식(간편 비밀번호/생체인증)은 마이 > 설정 메뉴에서 언제든 재변경 가능함을 명시
