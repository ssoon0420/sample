거래 / 전체 / 종목상세 / 정보

초안

기능정의 7개

1

헤더 + 탭 메뉴

- 상단에 뒤로가기, 종목명('안동 리모델링 1호'), 현재가(5,900원)+등락률(+68.5%), 찜(♡) 아이콘 - 하단에 정보/주문/호가/차트/내주문/커뮤니티 6개 탭, 현재 '정보' 탭이 밑줄로 활성 표시 - 상단 현재가는 5초마다 자동 갱신된다

2

투자 포인트

- 서버 등록 마크다운 본문(5개 항목 리스트) + 혜택 카드(골드 배경, 점 목록: '발효 한상 시식권', '10% 할인') + 지도 카드(가게 위치 + 하단 주소 텍스트) - 본문이 없으면 제목까지 생략되고, 혜택 미등록 시 카드가 사라지며, 주소·좌표 중 하나라도 없으면 지도 카드가 사라진다 - 배너 이미지가 있으면 좌우 스와이프 슬라이더 + 우하단 'n/N' 카운터가 뜨는데(1장이면 카운터 생략), 이 캡처에는 배너 이미지가 없다

3

분배정보 + 예상분배금 계산기

- 연 예상 분배율(4.92%, 서버값) / 월 예상 분배율(0.41%, 연분배율÷12를 소수 둘째자리까지 화면에서 계산) / 전월 분배금(개당 250원, 이력 없거나 0이면 '-') / 분배주기(3개월) - 우측 [예상분배금 계산기] 버튼 → 바텀시트: 전월 분배금액(수정불가, 회색) × 수량(기본값 10, 직접 입력 가능) = 예상 총 분배금액(빨간 강조) - 하단에 '※ 전월 분배금액 기준이므로 실제 분배금액과 차이가 있을 수 있습니다.' 주의 문구

이용약관 제2조(분배금·분배율 정의), 제14조(수익률 산정 안내) — 여기 표시되는 수치는 회사가 이동평균법으로 자체 계산한 참고용이며 실제 정산 금액과 차이가 발생할 수 있음을 계산기 내 주의 문구로 고지.

4

종목정보 + 문서

- 기업명(가게명)/시가총액/액면가/발행수량/유통수량/상장일 6행 표 - 등록된 PDF 문서 목록(예: audit_report_1.pdf, 문서 없으면 영역 자체가 생략) - 문서 행을 누르면 앱 내장 PDF 뷰어가 열린다(외부 다운로드 아님) - 참고: 발행·유통공시가 모두 0건인 종목은 '⑤ 공시' 섹션 자체가 표시되지 않는다 — 이 캡처가 그 경우

5

전월 개당 분배금 (접기/펼치기)

- 기본은 '전월 개당 분배금 250원' 한 줄 + 화살표로 접힌 상태 - 펼치면 분배월/개당 분배금(원)/총 분배금(원) 3열 표(최근 3개월치만) - 총 분배금 = 유통수량 × 개당 분배금(화면 계산) - 기획서상 원래 '전월 확정 분배금 팝업'으로 정의됐으나 실제 구현은 본문 내 접기/펼치기이므로, 본 기능정의서는 실제 구현 기준으로 작성함

6

같은 가게 종목

- 같은 가게의 다른 종목 카드 목록(종목명·가격·등락 + 찜 + [주문]) - 카드를 탭하면 그 종목 상세로 이동하며 화면이 완전히 새로 초기화된다(정보 탭·스크롤 최상단) - [주문] → 그 종목 주문 탭으로 바로 이동 - 찜 토글은 로그인이 필요, 나머지 열람은 비로그인도 가능 - 더보기 없이 서버가 내려준 전체 목록이 그대로 표시된다

7

하단 CTA (판매하기 / 구매하기)

- 화면 최하단 고정 버튼 2개 — [판매하기](파랑)/[구매하기](빨강) - 누르면 해당 방향 주문 탭으로 이동하며, 제출 시점에 로그인·계좌 연결 여부가 확인된다(정보 탭 열람 자체는 비로그인도 가능)
