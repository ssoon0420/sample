거래 / 전체 / 종목상세 / 내 주문

초안

기능정의 5개

1

헤더 + 탭 메뉴

- 뒤로가기 / 종목명 / 현재가+등락률 / 찜 - 하단 탭바 '내주문' 탭 활성

2

이 종목 요약 카드

- 계좌관리기관 뱃지('한국ST거래증권' + ⓘ) + [계좌변경 >] - 나의 평가금(1,200,000원, 손익 +613,405원(104.5%) 함께 표시) / 계좌잔고(60,063,088원, 펼침 화살표) - 평균 구매단가·보유수량은 이 종목 내 값 기준이며 미보유 시 '-' - 이 탭은 로그인+계좌연결 필수 — 비로그인 상태로 탭을 누르면 로그인 안내 토스트만 뜨고 탭이 열리지 않으며, 로그인했지만 미연결 상태로 URL 직접 진입 시 전체화면 안내('투자, 이제 시작만 남았어요.' + [계좌 연결하기])가 뜬다

이 요약 수치는 정보 탭과 마찬가지로 이동평균법 기준 참고 수치로, 증권사 실제 정산 금액과 차이가 있을 수 있다(이용약관 제14조).

3

필터 버튼

- 우상단 [필터] → 바텀시트 2개 섹션(주문상태: 전체/미체결/부분체결/체결완료/취소, 구매·판매: 전체/구매/판매) 각각 1개만 선택 가능(다중선택 불가, 비워두면 '전체' 처리) - 적용 시 목록이 처음 20건부터 다시 로드된다([더보기]로 펼친 내용은 접힘)

4

주문 카드 목록

- 카드 1건 = 날짜(YY.MM.DD) · 개당 N원 / 총 주문수량 + 구매|판매 / 상태 - 이 수량은 '총 주문수량'이며 미체결 잔량이 아니다(주문 탭 '대기' 목록과는 다른 개념) - 상태에 따라 우측에 수정(연필)·취소(✕) 아이콘이 붙는다 — 캡처의 '미체결' 카드(5,700원 1개 구매/미체결, 4,900원 1개 구매/미체결)에만 두 아이콘이 있고 '체결완료' 카드에는 없다 - 카드 본문 탭 → 구매정보/판매정보 상세 팝업 - 1회 20건, [더보기]로 20건씩 추가, 5초마다 자동 갱신(체결 시 수 초 내 상태 반영) - 정렬 옵션 없이 서버 순서 그대로

취소(✕)는 미체결/부분체결 잔여 수량에서만 가능 — 체결완료 건은 이미 증권 이전이 끝난 상태라 취소 불가(이용약관 제13조⑥).
