내 주문> 계좌변경

초안 로그인 후

기능정의 5개

1

기본 거래 계좌 설정 — 진입/닫기

- 내주문 탭의 [계좌변경 >]을 눌러 여는 화면(모달) - 제목 '기본 거래 계좌 설정', 우상단 X로 닫기 - 안내문: '주문은 기본 계좌로만 가능해요. 다른 계좌로 거래하려면 기본 계좌를 변경해주세요. 기본 계좌는 이 기기에서만 기억해요.'

2

현재 기본 계좌 카드

- 체크 표시된 카드가 현재 기본 계좌(예: 한국ST거래증권, 마스킹된 계좌번호) - 우측 [변경] 버튼으로 연결된 다른 계좌로 기본 계좌를 바꿀 수 있다

3

거래 계좌 추가 — 섹션

- '계좌를 추가하고 기본 계좌로 설정하면 바로 거래할 수 있어요' 안내 - 아직 연결하지 않은 증권사 목록이 아래에 카드로 나열된다

4

증권사별 연결 카드 (연계정보 동의 + 계좌 연결하기)

- 증권사명(예: 백년증권, KRST증권)마다 카드 1개 - [필수] 연계정보(CI) 수집·이용 및 제3자 제공 체크박스 — 우측 화살표로 상세 약관 확인 가능 - 체크 전에는 [계좌 연결 하기] 버튼이 비활성(회색)으로 보인다

연계정보(CI) 수집·이용 및 제3자 제공 동의는 계좌 연결 진행의 필수 동의 항목으로, 개인정보처리방침·이용약관과 연계된 정책 사항이다.

5

[완료] 버튼

- 계좌 설정을 마치고 화면을 닫는다(기본 계좌 변경 반영)
