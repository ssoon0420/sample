1

기간 선택 — '2026.08 ~ 2026.09 ▾'

- 기본 기간은 1개월 전 ~ 이번 달, 연·월 선택 시트로 변경 가능(최대 1년, 초과 선택 시 안내 팝업) - 기간을 바꾸면 목록이 20건부터 다시 로드된다

2

[필터] — 주문상태 · 구매/판매

- 주문상태(전체·미체결·부분체결·체결완료·취소) 1개 선택 + 구매/판매(전체·구매·판매) 1개 선택 — 각각 단일 선택만 가능 - 필터 변경 시 목록이 20건부터 다시 로드

3

주문 카드 — 미체결 (수정+취소 아이콘)

- 날짜(YY.MM.DD), 우측 상단에 연필(수정)·X(취소) 아이콘 — 미체결 주문에서만 둘 다 노출 - 하단에 가게·종목명, 개당 가격/수량·방향(구매=빨강), 상태 라벨

이용약관 제13조 6항: 미체결 또는 부분체결(잔여 수량) 상태의 주문은 직접 취소할 수 있으며, 취소 즉시 잠금(Lock)이 해제된다. 체결완료 상태의 주문은 이미 증권 이전이 완료되어 취소가 불가능하다.

4

주문 카드 — 체결완료 (아이콘 없음)

- 체결완료 상태는 수정·취소 아이콘이 사라진다(더 이상 되돌릴 수 없음) - 카드 본문을 탭하면 구매/판매정보 팝업(증권사·주문일시·상태·개당금액·총 수량)이 뜬다

5

주문 카드 — 부분체결 (수정 아이콘만, 잔여 수량 표기)

- 부분체결은 수정(연필) 아이콘만 노출(취소 아이콘 없음), 하단에 '부분체결(잔여 N개)' 표기 - 잔여 수량에 대해서만 수정·취소가 가능하다

이용약관 제13조 2항·4항: 주문 수량의 일부만 체결될 수 있으며 체결되지 않은 나머지는 유효기간(접수일로부터 30일) 내에 미체결 상태로 유지되고, 기간이 지나면 자동 취소된다.

6

뒤로가기

- 아이콘 버튼(←), href 없이 동적 동작으로 추정 - 클릭 시 이전 화면(종목 상세 등 진입 이전 화면)으로 복귀 - 별도 확인 팝업 없이 즉시 이동

7

상단 탭바 (주문내역 / 나의 수익 / 거래 한도)

- 3분할 세그먼트 버튼, 현재 '주문내역' 탭이 활성화(진한 배경)된 상태 - '나의 수익' 탭 클릭 시 종목별 수익률/평가금액 화면으로 전환 - '거래 한도' 탭 클릭 시 보유·연간거래·1일회전율 한도 현황 화면으로 전환 - 세 버튼 모두 href 없이 화면 내 콘텐츠만 전환되는 동적 탭 동작으로 추정

탭 전환만으로는 로그인/계좌 상태가 바뀌지 않으며, 비로그인·계좌 미연결 시 각 탭 진입이 제한될 수 있음

8

기본 거래 계좌 안내 (?)

- '한국ST거래증권' 배지 옆 물음표 아이콘 버튼 - 클릭 시 기본 거래 계좌의 의미(구매·판매 주문이 이 계좌로만 처리됨)를 설명하는 툴팁/팝업 노출로 추정 - href 없이 인앱 안내 레이어를 띄우는 동적 동작

구매·판매 주문은 기본 거래 계좌로만 가능하며, 여러 증권사 계좌를 연동한 경우 기본 계좌를 지정해야 함

9

계좌변경 버튼

- '⇄ 계좌변경 >' 버튼, href 없이 동적 동작으로 추정 - 클릭 시 연동된 여러 증권사 계좌 중 기본 거래 계좌를 선택/변경하는 화면 또는 바텀시트로 이동 - 변경 즉시 상단 카드의 평가금·계좌잔고·주문내역 목록이 새로 선택된 계좌 기준으로 갱신되는 것으로 추정

기본 거래 계좌 변경은 마이페이지 또는 거래 화면에서 언제든지 가능

10

나의 평가금 표시

- '나의 평가금 3,803,000원' 및 손익 '+370,372 (10.7%)' 텍스트 영역 (목록에 별도 href 없음, 순수 표시 요소로 추정) - 이동평균법(평균 매입단가) 기준 플랫폼 자체 계산 참고 수치 - 소수점 이하 절삭 표시로 실제 정산 금액과 차이가 발생할 수 있음 - 손익 상승 시 빨강, 하락 시 파랑으로 색상 구분되는 것으로 추정

표시되는 평가금·수익률은 참고용이며, 세금 계산 및 원천징수는 증권사에서 처리하므로 실제 손익과 다를 수 있음

11

계좌잔고 / 주문 대기 금액 펼침

- '계좌잔고 59,538,164원' 옆 화살표(⌄) 버튼, href 없이 동적 동작으로 추정 - 클릭 시 '주문 대기 금액'(미체결 구매 주문으로 잠긴 금액) 상세 내역이 펼쳐지는 것으로 추정 - 주문가능금액 = 계좌잔고 − 미체결 구매 주문 금액(수수료 포함)

구매 주문 시 주문금액+수수료가 잠금(Lock) 처리되며, 주문 취소 또는 체결 완료 시 즉시 해제됨. 화면상 잔고는 마지막 조회 시점 값으로 실제 체결 시 차이가 발생할 수 있음

12

조회 기간 선택 (2026.08~2026.09)

- 기간 드롭다운 버튼, href 없이 동적 동작으로 추정 - 클릭 시 월 선택 캘린더 팝업(닫기, ‹, ›, 1월~6월 등 월 버튼) 노출 - 기간 선택 후 적용하면 해당 기간의 주문/체결 내역만 목록에 재조회되어 처음부터 표시

13

필터 버튼

- '필터' 버튼, href 없이 동적 동작으로 추정 - 클릭 시 바텀시트가 열리며 '주문상태'(전체/미체결/부분체결/체결완료/취소)와 '구매/판매'(전체/구매/판매) 두 섹션에서 각각 1개만 선택 가능 - 적용 시 목록이 처음 20건부터 다시 로드됨(더보기로 펼친 내용은 초기화) - 선택 없이 적용하면 해당 섹션은 '전체'로 처리

14

주문 카드 - 체결완료 예시 (고요한상 안동 리모델링 1호)

- '26.09.14 개당 500,000원 / 1개 구매 / 체결완료' 카드, href 없이 동적 동작으로 추정 - 카드 본문 탭 시 해당 주문의 구매정보 상세 팝업(체결가·수량·수수료 등) 노출 - 체결완료 상태이므로 수정/취소 아이콘이 표시되지 않음(이미 증권 이전이 완료된 주문) - 수량은 미체결 잔량이 아닌 총 주문수량 기준으로 표시

체결완료 주문은 증권 이전이 완료된 상태이므로 취소 불가

15

주문 카드 - 미체결 예시 (노을다반 서귀포 리모델링 1호)

- '26.09.14 개당 6,200원 / 1개 판매 / 미체결' 카드, href 없이 동적 동작으로 추정 - 카드 본문 탭 시 판매정보 상세 팝업(미체결 잔량 펼치기 포함) 노출 - 미체결 상태이므로 우측에 수정(연필)·취소(×) 아이콘이 함께 노출됨 - 주문 목록은 5초마다 자동 갱신되어 체결 발생 시 수초 내 상태가 바뀜

주문 후 30일이 지나도 체결되지 않으면 자동 취소되며, 잠금(Lock)된 잔고도 함께 해제됨

16

수정(연필) 아이콘

- 미체결/부분체결(잔여 수량) 주문에만 노출되는 버튼, href 없이 동적 동작으로 추정 - 클릭 시 해당 주문 정보가 채워진 주문 폼(정정 모드)으로 이동 - 체결완료 주문에는 노출되지 않음

17

취소(×) 아이콘

- 미체결/부분체결(잔여 수량) 주문에만 노출되는 버튼, href 없이 동적 동작으로 추정 - 클릭 시 취소 확인 팝업이 뜨고, 확인 시 즉시 주문 취소 및 잠금(Lock) 해제 - 취소 직후 주문 목록·잔고·호가가 즉시 재조회되어 반영 - 체결완료 주문에는 노출되지 않음(취소 불가)

체결완료 상태는 이미 증권 이전이 완료되어 취소가 불가능함
