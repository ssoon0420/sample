거래 / 전체 / 종목상세 / 호가

초안 로그인 후

기능정의 5개

1

헤더 + 탭 메뉴

- 뒤로가기 / 종목명('서귀포 리모델링 1호') / 현재가(5,000원)+등락률(0.0%) / 찜 - 하단 탭바에서 '호가' 탭 활성 - 다른 탭과 달리 호가 탭에는 하단 CTA(판매하기/구매하기)가 없다 — 주문 진입은 호가 가격을 직접 눌러서 이루어진다

2

우측 통계 패널

- 마지막 체결가(ⓘ 툴팁, 누르면 뜨고 3초 후 자동으로 닫힘) - 시작(당일 시가) / 고가(빨강) / 저가(파랑) / 거래량 / 거래액 - 매도 호가 칼럼 옆에 고정되어 항상 노출

3

매도 호가 목록 (파랑, 상단)

- 수량바(그쪽 최대 수량 대비 비율로 막대 길이 결정) + 매도가(파랑)/등락률 - 가격을 탭하면 하단에 플로팅 pill이 뜨고 [구매] 쪽이 강조(그 가격에 살 수 있으므로)된다 - 값이 바뀐 행은 잠깐 반짝이는 플래시 효과 - 매도 호가가 없으면 '지금 판매중인 호가가 없어요.' 안내

4

중앙 헤더 (판매대기 / 금액 / 구매대기)

- 판매대기(파랑, 매도 호가 총 수량) / 구매대기(빨강, 매수 호가 총 수량) - 화면 진입 시 이 헤더가 세로 중앙에 오도록 자동 스크롤되며, 호가 수가 적어도 중앙 위치가 유지된다

5

매수 호가 목록 (빨강, 하단)

- 매수가(빨강)/등락률 + 수량바(매도측과 좌우 반전 배치) - 가격을 탭하면 플로팅 pill에서 [판매] 쪽이 강조된다 - 강조되지 않은 반대쪽 버튼도 눌러 반대 방향 주문이 가능(양방향) - 매수 호가가 없으면 '지금 구매중인 호가가 없어요.' 안내 - 호가·수량·통계 전체가 5초마다 자동 갱신된다

이용약관 제12조(호가 단위): 2,000원 미만 10원 ~ 50,000원 이상 1,000원까지 가격 구간별 호가 단위가 있고, 단위에 맞지 않는 입력값은 하위 호가로 자동 보정된다 — 호가 목록의 가격들도 이 단위를 따른다.
