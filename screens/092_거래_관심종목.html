거래/관심종목

거래 / 관심 / 관심종목

편집중 로그인 후

기능정의 16개

1

관심종목 탭 헤더 — 'N건' + 정렬

- '관심종목 10건'은 서버가 알려주는 총 건수(화면에 10건만 보여도 정상) - 우측 정렬은 전체 탭과 동일한 6종(많이 오른순·거래량 많은순·거래대금 높은순·시가총액 높은순·최근 상장순·가나다순) 중 선택, 기본은 많이 오른순

2

종목 카드 — 썸네일/가게명/종목명/가격·등락

- 좌측 원형 썸네일 + 가게명(작게) + 종목명(굵게), 우측에 현재가와 등락률(▲빨강/▼파랑) - 카드 본문을 탭하면 종목 상세로 이동

3

[주문] 버튼

- 로그인 필요 — 누르면 해당 종목 상세의 주문 탭으로 바로 이동한다 - 비로그인 상태에서 누르면 로그인 화면으로 유도

4

찜(♥) 아이콘 — 채워진 하트

- 관심종목 목록이므로 모든 카드의 하트가 채워진 상태(이미 찜한 종목) - 다시 누르면 관심 해제되어 목록에서 즉시 사라진다(찜 목록 조회 시 즉시 반영)

5

무한 스크롤 로드 (10건 단위)

- 끝까지 내리면 10건씩 자동 추가([더보기] 버튼 없음) - 마지막까지 불러오면 더 요청하지 않는다 - 관심 종목이 없거나 조회 실패 시 '관심 종목이 없어요' + '가장 많이 찜한 종목' 추천 목록으로 대체된다(0건과 실패가 같은 화면이라 구분되지 않음 — U-13)

6

필터 버튼

- 관심종목 목록 상단 우측의 [필터] 버튼 - href 없음 → 탭하면 필터 바텀시트/드롭다운을 여는 동적 동작으로 추정 - 제공된 상세 문서(내주문 탭 기준)에서는 필터가 섹션별 단일 선택 + 전체 방식이었음 — 관심종목 화면의 필터 항목(정렬/유형 등)은 스크린샷만으로는 옵션 구성을 단정할 수 없어 확인 필요 - 적용 시 목록이 다시 그려질 것으로 추정

7

관심종목 건수 및 정렬 기준

- "관심종목 10건" — 현재 로그인 회원이 등록한 관심종목의 총 개수 표시 - 우측 "많이 오른순" 텍스트는 현재 적용된 정렬 기준으로 추정되며, 탭 시 정렬 옵션 선택 UI가 열릴 가능성이 있음(스크린샷만으로 확정 불가) - 링크/버튼 목록에 별도 href가 감지되지 않아 정렬 변경 가능 여부는 추정

8

관심종목 카드 (행 단위)

- 종목 아이콘 + 가게명(예: 화덕담) + 종목명(예: 대구 분점개설 3호) + 현재가 + 전일대비 등락률로 구성된 리스트 카드 - 카드 본문(아이콘·텍스트 영역) 탭 시 href 없음 → 해당 종목 상세 화면(정보 탭)으로 이동하는 동적 동작으로 추정 - 현재가는 가장 마지막에 체결된 가격이며, 등락률은 전일 마지막 체결가 대비 오늘 현재가의 변화폭/등락률(회사 정책상 전일 거래 없으면 최근 거래일 체결가 기준) - 로그인 필요 — 관심종목 설정/열람은 로그인 회원만 이용 가능(제11조②)

표시가는 다자간상대매매 특성상 실시간 체결과 다를 수 있으며, 화면 표시 금액과 실제 주문가능금액에 차이가 발생할 수 있음

9

주문 버튼

- 각 관심종목 카드 우측의 [주문] 버튼 - href 없음 → 탭 시 해당 종목의 주문(거래) 화면으로 이동하는 동적 동작으로 추정 (제공 문서상 "같은 가게 종목 [주문] → 그 종목의 주문 탭" 패턴과 동일한 동작으로 추정) - 주문 화면에서는 지정가 주문만 가능하며 시장가 주문은 제공되지 않음 - 로그인 및 증권사 계좌 연결이 되어 있지 않으면 주문 제출 시 안내 토스트 또는 계좌 연결 안내가 표시될 것으로 추정 - 입력 가격이 호가 단위(가격 구간별 10원~1,000원)에 맞지 않으면 하위 호가로 자동 보정됨

체결 금액의 0.1%가 플랫폼 유통 수수료로 부과됨(이벤트 시 한시적 감면 가능). 거래 가능 시간은 평일 08:00~20:00이며 주말·공휴일·대체휴무일 등에는 거래 불가

10

관심종목 해제(찜) 버튼

- 각 카드 우측 끝의 하트 아이콘(unfavorite) 버튼 - href 없음 → 탭 시 해당 종목을 관심종목에서 즉시 해제하는 토글 동작으로 추정 - 해제 시 목록에서 즉시 사라지며 상단 "관심종목 N건" 카운트가 갱신될 것으로 추정 - 로그인 필요 — 관심종목 설정은 로그인 회원만 가능(제11조②)

11

관심종목/관심가게 전환 토글

- "관심" 대탭 하위의 서브 토글 — [관심종목](선택됨) / [관심가게] - href 없음 → 탭 시 관심종목 목록과 관심가게 목록 사이를 전환하는 동적 동작으로 추정 - 현재 화면은 "관심종목"이 활성화된 상태(진한 배경으로 강조) - 관심가게로 전환 시 카드 구성(주문 버튼 등)이 달라질 것으로 추정되나 스크린샷 없이 단정 불가

12

거래 화면 상단 탭 (전체 / 보유 / 관심)

- 거래 화면 최상단의 3개 대탭: [전체] · [보유] · [관심](현재 선택) - href 없음 → 탭 시 각 목록(전체 종목, 보유 종목, 관심 종목)으로 화면 전환하는 동적 동작으로 추정 - "보유" 탭은 로그인 및 계좌 연결이 필요한 내주문/보유 내역과 연관된 것으로 추정(비로그인 시 로그인 안내, 계좌 미연결 시 계좌 연결 안내가 뜰 것으로 추정) - "전체"·"관심"은 로그인 없이도 종목 탐색 자체는 가능하나, 관심종목 등록·주문은 로그인 필요

13

프로필/계정 버튼 ("하")

- 상단 우측 원형 아바타 버튼(이니셜 "하" 표시) — 로그인한 회원 계정임을 시사 - href 없음 → 탭 시 계정/프로필 관련 메뉴 또는 MY 화면으로 이동하는 동적 동작으로 추정 - 정확한 이동 대상은 감지된 링크 목록에 없어 단정 불가

14

알림 버튼

- 상단 우측 종 모양 알림 아이콘 버튼 - href 없음 → 탭 시 알림 목록/센터 화면을 여는 동적 동작으로 추정 - 서비스 정책상 주문 만료 임박(만료 7일 전·당일), 소득적격 자격 만료 임박(30일 전), 거래정지/재개 등 주요 이벤트가 앱 알림으로 발송되므로 해당 알림들이 이 화면에 모일 것으로 추정

15

화면 타이틀 "거래"

- 현재 화면이 "거래" 메뉴임을 나타내는 정적 타이틀 텍스트 - 별도의 클릭/이동 동작 없는 순수 라벨로 추정
