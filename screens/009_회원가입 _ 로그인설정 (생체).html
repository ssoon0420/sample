회원가입 / 로그인설정 (생체)

편집중

기능정의 6개

1

뒤로가기

- 좌상단 화살표 아이콘 버튼 - 탭 시 이전 화면(직전 가입 단계)으로 돌아감 - 화면에서 감지된 링크/버튼 목록에 해당 요소가 없어 실제 이동 대상은 스크린샷상 추정이며 단정할 수 없음

2

간편 로그인 설정 안내 타이틀

- "로그인, 더 쉽게 할 수 있어요. 간편 로그인 방식을 설정해주세요." 문구 - 회원가입 절차 중 로그인 방식(간편 인증) 설정을 유도하는 안내 텍스트 - 별도의 클릭/입력 동작 없는 정보성 텍스트

3

간편 인증으로 로그인 선택 박스

- 좌측에 잠금/인증 아이콘(****)과 "간편 인증으로 로그인" 라벨이 있는 선택형 박스(현재 진한 테두리로 선택된 상태로 보임) - 탭 시 간편 비밀번호(PIN) 또는 생체인증(지문·안면) 등 간편 인증 수단 등록 절차로 진입할 것으로 추정됨 - 화면에서 감지된 링크/버튼 목록에 해당 요소가 없어 실제 이동 대상(href)은 확인되지 않으며 스크린샷 기반 추정임 - 자본시장법 제5조에 따르면 로그인 방식은 아이디/비밀번호, 간편 비밀번호(PIN), 생체인증 3가지로 구분됨 — 이 화면은 그중 간편 인증 방식 설정 단계로 보임

4

로그인 방식 변경 안내 문구

- "※ 로그인 방식은 마이 > 설정에서 언제든 바꿀 수 있어요." 안내 텍스트 - 별도 클릭 동작 없는 정책 고지성 문구로 추정됨(밑줄·색상 등 링크 스타일 미확인) - 감지된 링크 목록에 없어 실제로 탭 가능한 요소인지는 단정할 수 없음

로그인 방식은 가입 이후에도 마이페이지 > 설정 메뉴에서 언제든지 변경 가능함을 고지

5

취소 버튼

- 하단 좌측 보조 버튼(흰 배경) - 탭 시 간편 로그인 설정을 건너뛰고 이전 화면 또는 다음 가입 단계로 이동할 것으로 추정(스크린샷만으로 정확한 이동 대상 단정 불가) - 감지된 링크/버튼 목록에 항목이 없어 실제 동작은 확인되지 않음

6

확인 버튼

- 하단 우측 메인 액션 버튼(진한 남색 배경, 강조) - 선택된 간편 인증 방식으로 로그인 설정을 확정하고 다음 단계(예: PIN 등록 또는 생체인증 등록, 혹은 가입 완료)로 진행하는 액션으로 추정됨 - 감지된 링크/버튼 목록에 항목이 없어 실제 이동 대상(href)은 확인되지 않으며 스크린샷 기반 추정임 - 유효성검사: 상단의 간편 인증 옵션이 선택되지 않은 상태에서 탭 시 선택을 요구하는 안내가 표시될 가능성이 있음(화면상 확인 불가)
