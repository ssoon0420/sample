MY/정보설정

MY / 설정 / 정보설정

초안 로그인 후

기능정의 6개

1

로그인 방식 설정 — 간편인증 / 생체인증 토글

- 간편인증 로그인: 등록 전이면 '등록' 배지(등록 후에는 '수정'). 토글 ON 시 토스트 '본인인증 후 새 PIN을 등록합니다.' → 본인인증(MOK, 로그인 계정과 일치 확인) → 보안 키패드 2회 입력 → 등록 성공 시 토글 ON + '간편인증이 등록되었어요.' - 생체 인증 로그인: ON 시 기기에 생체 미등록이면 사유 토스트와 함께 토글이 원복되고, 앱에 미등록이면 생체 등록 화면으로 이동 - 두 토글은 상호배타 — 한쪽을 켜면 다른 쪽이 자동으로 꺼진다. OFF는 서버의 PIN을 삭제하는 것이 아니라 '기본(아이디/비밀번호) 방식으로 되돌리기'일 뿐이다

2

알림 설정 — 커뮤니티 / 새로운소식 / 고객지원

- 커뮤니티(보유·관심종목 새 글) / 새로운소식(공지·상장정보) / 고객지원(1:1 문의 답변) — 토글 즉시 서버 저장, 실패 시 원복 - 이벤트 알림 행은 발송 채널 미구현으로 임시 비노출(서버 필드는 유지되어 과거에 켜둔 계정은 값이 남아 있다) - 주문·보안 등 필수 안내는 이 설정과 무관하게 항상 자동 발송된다

3

위치 (선택)

- OS 위치 권한을 그대로 비추는 토글 — 앱에서 끄는 것은 불가('위치 권한은 기기 설정에서 해제할 수 있어요.' 안내) - 영구 거부 상태면 [기기 설정] 칩이 나타나 OS 설정으로 이동시킨다. 화면에 복귀할 때마다 권한을 재확인한다 - PC 브라우저에서는 위치 조회가 항상 '미지원' 취급되어 토글이 정상 동작하지 않는다(실기기 전용 기능)

4

해외 이용 잠금 여부

- 서버 저장 토글, 실패 시 원복 + '해외 이용 설정 변경에 실패했어요.' 안내 - 라벨('잠금 여부')과 설명 문구('해외에서 주문·거래가 가능하도록 허용해요')의 방향이 반대로 읽히는 알려진 제약(U-27) — ON이 '잠금'인지 '허용'인지 헷갈리기 쉽다

5

로그아웃

- 확인 팝업 없이 즉시 로그아웃되고 토스트 '로그아웃 후 홈으로 이동되요.' 후 홈으로 이동한다(알려진 제약 U-30 — 오탭 시 바로 로그아웃됨)

6

회원탈퇴

- 탭하면 회원 상태 확인 화면(/auth/withdraw)으로 이동한다

회원은 언제든지 앱에서 탈퇴를 신청할 수 있으며, 회사는 관련 법령에 특별한 제한이 없는 한 즉시 처리한다(이용약관 제7조①).
