더보기 / 이벤트 / 이벤트상세

초안

기능정의 5개

1

닫기(X)

- 상세 화면을 닫고 이벤트 목록으로 복귀

2

타이틀 + 기간

- 제목 → (배지 + 기간) → 본문 → 상세 이미지 순으로 배치 - 목록과 달리 상세에서는 '진행중' 상태일 때 배지가 표시되지 않고, 대기·종료 상태에만 배지가 노출된다 - 상세를 열 때마다 조회수가 +1 되며 중복 방어가 없어 새로고침마다 계속 증가한다

3

이벤트 기간 / 당첨자 발표 안내

- 이벤트 기간과 당첨자 발표일, 당첨 발표 방식(앱 내 알림 + 개별 문자 통보) 안내 - 경품 발송(당첨 확인 후 14일 이내)과 등수별 수령 방법(배송지 입력 후 택배 / 모바일 쿠폰 문자) 구분 안내

4

경품 목록

- 등수별 경품 항목과 수량을 리스트로 나열(예: 아이패드 프로 1명, 다이슨 에어랩 컴플리트 3명 등)

5

참여 방법 및 유의사항

- 참여 방법 3단계: ① 앱 실행 ② 가입 계정으로 로그인 ③ 자동 응모 완료(별도 신청 불필요) - 유의사항: 당첨 시 개인정보(성명, 주민등록번호 등) 제공에 동의해야 경품 수령이 가능하며, 당첨 발표 후 7일 이내 수령 정보 미제출 시 당첨이 취소된다
