회원가입 / 본인인증_정책

편집중

기능정의 4개

1

본인인증 실패 안내 아이콘

- 경고(⚠) 표시가 있는 노트북 일러스트로, 본인인증 절차 중 오류가 발생했음을 시각적으로 알림 - 별도의 클릭/탭 동작 없는 순수 안내용 이미지

2

실패 안내 타이틀

- "본인인증에 실패했습니다." 굵은 글씨의 메인 안내 문구 - 회원가입 절차 중 본인인증(실명인증·휴대폰 인증 등) 처리 과정에서 오류가 발생했을 때 노출되는 전체화면 에러 상태로 추정됨

3

실패 사유 및 재시도 안내 문구

- "본인인증 중 오류가 발생했습니다." / "잠시 후 다시 시도해 주세요." 2줄의 보조 설명 텍스트 - 구체적인 실패 사유(통신사 인증 실패, 타임아웃 등)를 구분하지 않고 공통 안내 문구만 노출되는 것으로 보임 - 사용자에게 즉시 재시도를 유도하는 문구

4

확인 버튼

- 화면 하단 고정된 짙은 남색 배경의 전체 폭 버튼 - 감지된 href/이동 대상 정보가 없어 정확한 이동 경로는 확정할 수 없음 - 일반적인 에러 화면의 '확인' 버튼 패턴을 고려하면, 탭 시 이전 본인인증 입력 화면(또는 회원가입 시작 화면)으로 돌아가 재시도할 수 있도록 하는 동작으로 추정됨 (확정 아님) - 별도 유효성검사 없이 단순 확인/닫기 액션으로 추정
