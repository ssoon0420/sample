거래/보유/거래 한도

거래 / 보유 / 거래 한도

편집중 로그인 후

기능정의 17개

1

거래한도 탭 — 계좌 게이트 없음

- 다른 두 탭(주문내역·나의 수익)과 달리 이 화면은 계좌 게이트가 없어 로그인·계좌 미연결 상태에서도 0원/0%로 그려진다(알려진 제약 U-09) - 한도가 '무제한'인 계정도 화면상 0원으로 보일 수 있다(U-10, 표기 검토 필요)

2

조회 기간 표시 — '2026년.01~ 현재'

- 한도 산정 기준 기간을 안내(연초부터 현재까지) - 탭 진입마다 재조회되며 자동 갱신은 없다

3

보유한도 게이지 — ⓘ 툴팁

- '보유한도' 옆 ⓘ 를 누르면 3초 후 자동으로 닫히는 설명 툴팁이 뜬다 - 현재 보유 금액(빨강, 구매 후 보유 금액 기준) / 한도 / 진행 바 / 예상 잔여 금액을 함께 보여준다

이용약관 제10조 3항: 보유 한도는 일반회원 1,000만 원 / 소득적격회원 3,000만 원이며, 구매 후 현재 보유 금액(수수료 제외) 기준으로 산정된다. 한도 초과 시 기존 보유 종목을 판매해야 추가 구매가 가능하다.

4

연간거래한도 게이지

- 올해 1월 1일부터 현재까지 판매한 누적 총액을 자동 계산해 표시(1년간 판매 금액 기준) - 예상 잔여 금액을 함께 표시

이용약관 제10조 3항: 연간거래 한도는 일반회원 4,000만 원 / 소득적격회원 8,000만 원이며, 올해 1월 1일부터 현재까지 판매한 누적 총액 기준으로 자동 계산된다.

5

1일 회전율 게이지 (오늘 사용 0% / 허용 100%)

- 오늘 거래한 활동량을 판매 금액 비율로 표시, 허용치는 100% - 100% 초과 시 다음 영업일부터 거래 가능(당일 추가 거래 불가)

이용약관 제10조 3항 및 제13조 3항: 1일 회전율은 하루 동안 판매한 금액이 현재 보유 금액의 100%를 초과할 수 없으며, 초과 시 다음 영업일부터 거래가 가능하다.

6

뒤로가기

- 좌측 상단 화살표 아이콘 버튼 - 클릭 시 이전 화면(거래/보유 진입 전 화면)으로 이동 - href 정보 없이 앱 내 뒤로가기 동작으로 추정됨

7

거래 한도 탭 (현재 선택됨)

- '거래/보유' 메뉴 내 3개 탭('주문내역', '나의 수익', '거래 한도') 중 하나 - 현재 화면은 '거래 한도' 탭이 활성 상태(진한 남색 배경)로 선택되어 있음 - 회원 등급별 보유한도·연간거래한도·1일 회전율 현황을 확인하는 화면 - 로그인 및 증권사 계좌 연결이 완료된 회원만 접근 가능

한도(보유 금액, 연간거래 한도, 1일 회전율)는 주문 제출 시점에 시스템에서 확인하며, 거래가 체결될 때 최종 반영됩니다. 한도를 초과하는 주문은 자동 거부됩니다.

8

주문내역 탭

- 탭 클릭 시 주문내역(체결/미체결 등) 조회 화면으로 이동 - href 정보가 없어 화면 내 상태 전환(탭 전환) 방식의 동적 동작으로 추정 - 비로그인 상태에서는 이용이 제한되며, 로그인 안내가 표시될 수 있음 - 계좌 미연결 시 계좌 연결 안내가 표시될 수 있음

9

나의 수익 탭

- 탭 클릭 시 회원의 투자 수익률/평가금액 조회 화면으로 이동 - href 정보가 없어 탭 전환 방식의 동적 동작으로 추정 - 표시되는 수익률·평가금액은 플랫폼이 이동평균법(평균 매입단가) 기준으로 자체 계산한 참고 수치로 실제 정산 금액과 차이가 발생할 수 있음

수익률과 평가금액은 소수점 이하를 절삭하여 표시되므로 실제 손익과 차이가 있을 수 있습니다. 세금 계산 및 원천징수는 증권사에서 처리합니다.

10

연동 증권사 선택 뱃지

- '한국ST거래증권' 등 연동된 계좌관리기관(증권사) 명이 표시된 뱃지형 UI - 여러 증권사 계좌를 동시에 연동한 경우 선택하여 해당 계좌 기준 한도 정보를 전환 조회하는 용도로 추정 - 구매·판매 주문은 기본 거래 계좌로 설정된 계좌 기준으로만 가능

한도는 해당 증권사(한국ST거래)의 연결 계좌 합계 금액을 기준으로 적용됩니다.

11

조회 연도 선택 뱃지

- '2026년' 등 조회 기준 연도를 나타내는 뱃지형 UI - 연간거래한도는 해당 연도 1월 1일부터 현재까지의 누적 판매 총액 기준으로 계산되므로, 연도 전환 시 하단 '연간거래한도' 값이 갱신될 것으로 추정

12

계좌잔고 요약 카드

- 연동 증권사 및 조회 연도 하단에 계좌잔고 금액(예: 59,538,164원)을 표시 - 실제 구매·판매 가능 여부는 주문 제출 시점에 재확인됨 - 화면에 표시되는 계좌 잔고는 마지막으로 조회된 정보이며 실시간 값과 차이가 발생할 수 있음

계좌 잔고, 한도는 마지막 주문 기준으로 표시되며, 실제 주문 시 다를 수 있어요.

13

보유한도 섹션 및 도움말(?)

- 제목 옆 물음표(?) 아이콘 탭 시 '보유한도' 용어에 대한 설명 툴팁/팝업이 뜨는 것으로 추정 - 보유한도는 구매 후 현재 보유 금액 기준(수수료 제외)으로 산정 - 한도 초과 시 기존 보유 종목을 판매한 후에만 추가 구매가 가능

일반 회원 보유한도: 1,000만 원 / 소득적격 회원 보유한도: 3,000만 원

14

보유한도 현황 (현재 보유 / 한도 / 예상 잔여)

- 좌측에 현재 보유 금액(3,497,848원, 빨간색 강조), 우측에 한도(10,000,000원) 표시 - 하단 그라디언트 진행 바(오렌지→레드)로 한도 대비 사용률을 시각화 - 진행 바 아래 '예상 잔여' 금액(6,502,152원)을 함께 표시하여 추가로 보유 가능한 금액을 안내 - 별도 입력/클릭 동작은 없는 단순 정보 표시 요소로 추정

구매 후 현재 보유 금액 기준(수수료 제외)이며, 한도 초과 시 기존 보유 종목 판매 후 구매가 가능합니다.

15

연간거래한도 섹션

- 도움말(?) 아이콘 탭 시 '연간거래한도' 용어 설명이 뜨는 것으로 추정 - '올해 판매' 누적 금액(95,800원)과 '한도'(40,000,000원)를 상하 대비로 표시 - 진행 바로 사용률을 표시하고, 하단에 '예상 잔여' 금액(39,904,200원) 표시 - 올해 1월 1일부터 현재까지 판매한 누적 총액을 기준으로 자동 계산됨

일반 회원 연간거래한도: 4,000만 원 / 소득적격 회원 연간거래한도: 8,000만 원

16

1일 회전율 섹션

- 도움말(?) 아이콘 탭 시 '1일 회전율' 용어 설명이 뜨는 것으로 추정 - '오늘 사용' 비율(0%)과 '허용' 한도(100%)를 상하 대비로 표시 - 진행 바로 오늘 거래 활동량 대비 사용률 표시, 하단에 '예상 거래 가능금액'(59,538,164원) 표시 - 오늘 거래한 활동량 기준으로 계산되며, 당일 100% 초과 시 다음 영업일부터 거래 재개

일반 회원·소득적격 회원 모두 1일 회전율 100% 이하로 제한됩니다. 하루 판매 금액이 보유 금액의 100%를 초과하면 다음 영업일부터 거래가 가능합니다.
