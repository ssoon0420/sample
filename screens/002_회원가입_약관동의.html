회원가입/약관동의

회원가입 / 약관동의

초안 로그인 후

기능정의 5개

1

진행 단계 표시

- 화면 좌측 상단에 뒤로가기 버튼, 우측에 전체 3단계 중 현재 단계를 'N / 03' 형식으로 표시 - 그 아래 진행 바(주황색)가 현재 단계만큼 채워진다 - 회원가입은 약관동의(01) → 본인인증(02) → 회원정보 입력 등으로 이어지는 멀티스텝 폼이며, 뒤로가기를 누르면 이전 단계(첫 단계에서는 가입 진입 전 화면)로 돌아간다

2

안내 타이틀

'서비스 이용을 위한 약관에 동의해 주세요.' 2줄 안내 문구. 이 화면의 목적(약관 동의)을 굵은 글씨로 바로 인지시킨다.

3

[필수] 전체동의 토글

- 좌측 체크박스 + 우측 펼침/접힘 화살표(v)로 구성된 아코디언 헤더 - 체크하면 하위 4개 약관이 모두 체크되고, 화살표를 누르면 하위 항목 목록이 펼쳐지거나 접힌다(캡처는 펼쳐진 상태) - '[필수]' 라벨대로 이 전체동의(=하위 4개 모두 동의)가 완료돼야 다음 단계로 진행할 수 있다

이용약관 제4조②: '서비스에 가입하려는 사람은 본 약관에 동의하고, 회사가 요구하는 본인인증 절차를 완료하여야 한다' — 이 화면이 그 시작 지점이다.

4

개별 약관 체크리스트 (4개)

- [필수] 개인정보 수집·이용 동의 / [필수] 통신사 이용 약관 / [필수] 서비스 이용약관 / [필수] 투자자 유의사항, 총 4행 - 각 행은 체크박스 + 우측 '>' 화살표로 구성되며, 화살표(또는 문구)를 누르면 해당 약관 전문이 뜨는 화면/바텀시트로 이동할 것으로 추정(현재 캡처만으로 상세 진입 UI는 확인 불가 — 실기기 검증 필요) - 4개 모두 체크돼야 전체동의가 활성화되고 [다음] 버튼도 활성화된다

'서비스 이용약관' 항목은 실제 이용약관 전문(제1~21조)과, '투자자 유의사항'은 AI매칭 비권유·수익률 참고용 등 투자자 보호 고지사항과 정확히 연결되는지 QA 필요.

5

하단 [다음] 버튼

- 화면 하단 고정 버튼 - 캡처 시점(전부 미체크)에는 비활성(회색)으로 보인다 - 필수 약관 4개가 모두 체크돼야 활성화되며, 누르면 다음 단계(02/03, 본인인증)로 이동할 것으로 추정된다 - 일부만 체크한 상태에서의 동작(비활성으로 클릭 자체가 막히는지, 클릭 시 안내 토스트가 뜨는지)은 실기기 확인 필요
