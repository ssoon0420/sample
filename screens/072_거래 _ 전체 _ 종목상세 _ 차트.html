거래 / 전체 / 종목상세 / 차트

초안 로그인 후

기능정의 6개

1

헤더 + 탭 메뉴

- 뒤로가기 / 종목명 / 현재가+등락률 / 찜 - 하단 탭바 '차트' 탭 활성

2

TradingView 차트 영역

- 우상단 [확대/축소]·[설정(톱니)] 아이콘 - 확대하면 차트가 화면 전체를 채우고 하단 시세 표 2개가 사라진다 - 보이는 구간의 최고가(빨강 ↓)·최저가(파랑 ↑) 위치에 '{가격} ({날짜})' 라벨이 붙고 구간 이동 시 재계산된다 - 캡처에는 '내 종목 평균'(하늘색 점선, 4,888원)과 '구매'/'판매' 표식이 표시되어 있다 — 설정에서 해당 옵션이 켜진 상태 - 로드 실패 시 '차트를 불러올 수 없어요' 문구

설정의 '내 종목 평균'·'구매/판매 표시' 체크는 로그인+계좌연결이 필요하며, 미충족 시 체크 시점에 로그인/계좌연결 안내가 뜬다.

3

기간 · 캔들/라인 · 설정저장

- 기간 [일]/[주]/[월](기본 '일') / 차트 모양 [캔들]/[라인](기본 '캔들') 즉시 전환 - 설정 바텀시트의 '내 종목 평균'·'구매/판매 표시'·'거래량' 3개 옵션은 [저장하기]를 눌러야 반영 - 이 설정은 이 기기의 브라우저에 저장되어 다른 기기·데이터 삭제 시 기본값(전부 켜짐)으로 복원된다

4

체결시세 표 (5행)

- 일시/체결가(원)/등락율/체결량(개) - 확대 상태가 아닐 때만 노출, 최근 5건 - 자동 갱신 없음(재진입해야 최신값 반영 — 5초 자동갱신되는 상단 현재가와 어긋나 보일 수 있으나 정상) - [더보기] → 시세 화면(체결시세 탭 선택 상태로 진입)

5

일별시세 표 (5행)

- 일시/체결가(원)/등락율/체결량(개) - 60초 이내 재진입 시 캐시된 값 표시 - [더보기] → 시세 화면(일별시세 탭) - 시세 전용 화면은 탭바 없이 뒤로가기로만 나갈 수 있고 하단 CTA는 그대로 있으며, 목록은 30건씩 커서 방식으로 누적된다

6

하단 CTA (판매하기 / 구매하기)

화면 최하단 고정. 누르면 로그인·계좌 연결 확인 후 주문 탭으로 이동.
