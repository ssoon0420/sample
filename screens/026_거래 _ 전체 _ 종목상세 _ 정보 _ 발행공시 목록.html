거래 / 전체 / 종목상세 / 정보 > 발행공시 목록

초안

기능정의 4개

1

헤더 — 뒤로가기만, 화면 제목 없음

- 헤더에 제목이 표시되지 않고 뒤로가기 화살표만 있다(알려진 제약 U-34 — '공시' 타이틀이 렌더되지 않는 구조) - 뒤로가기를 누르면 종목 상세로 돌아간다

2

세그먼트 — 발행공시 / 유통공시

- 정보 탭의 공시 섹션 [더보기]로 들어오면 그 탭(발행/유통)이 선택된 채 열린다 - 탭을 바꿔도 URL은 바뀌지 않아 뒤로가기로 탭만 복귀할 수는 없다

3

공시 목록 항목 — 제목(1줄 말줄임) + 날짜

- 항목을 누르면 오른쪽에서 상세가 오버레이로 밀려 들어온다(별도 URL 아님) - 한 번에 최대 100건만 로드되며 [더보기]·무한스크롤이 없다 — 100건 초과분은 열람 불가 - 정렬 기준은 서버 순서(문서상 미확인)

4

로딩 표시 없음 / 빈 상태

- 목록 로딩 중 별도 표시가 없어 느린 네트워크에서는 빈 목록처럼 보일 수 있다 - 공시가 0건인 종목은 '공시가 없어요' 안내 - 비로그인 상태에서도 열람 가능
