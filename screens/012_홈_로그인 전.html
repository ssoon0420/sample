기능정의 11개

1

헤더 — 프로필칩·알림벨 (비로그인)

- 좌측 로고, 우측 프로필칩·알림 벨 아이콘 - 비로그인 상태이므로 프로필칩은 사진없이 기본 회색 아이콘으로 표시되며, 탭하면 로그인 화면으로 이동 - 알림 벨은 노출되지만 로그인이 필요한 기능 — 비로그인 상태로 탭하면 로그인 게이트가 뜨고, 안읽음 개수 배지도 로그인 상태에서만 조회됨

2

메인 배너

- 서버가 노출 순서를 정한 배너를 좌우 스크롤로 최대 10개까지 노출(현재 페이지 인디케이터 '1/2'로 표시) - 자동 넘김 없음 — 손으로 직접 밀어야 다음 배너 표시 - 노출 중인 배너가 0건이면 섹션 자체가 사라짐 - 배너 탭 시 각 배너에 지정된 목적지로 이동

3

빠른 안내 카드 (백년가게란·주문방법·가디언이란·가디언혜택)

- 원형 이미지 카드 4종, 이미지·위치 고정 - 각 이미지 클릭시 해당하는 페이지로 이동

4

종목 목록 '가디언 픽'

- 상장 종목만 조회(상장폐지 제외), 5개를 좌우 스크롤 카드로 노출 - 의도된 정렬은 '등락률 높은순'으로 노출 - 카드 구성: 가게명·종목명·현재가·등락률·[주문]·찜(♡) 아이콘 - 비로그인 상태라 찜(♡)은 테두리만 있는 빈 하트로 표시 — 탭하면 로그인 게이트, [주문]은 화면은 열리되 제출 시점에 로그인 요구 - 카드 탭 → 종목 상세로 이동 - 의도된 정렬 기준은 '등락률 높은순'이지만, 서버가 정렬 조건을 아직 반영하지 않아 실제로는 '최근 상장순'으로 노출된다(알려진 제약, 참고: 10-home.md) — 그 결과 '새로운 종목' 섹션과 종목이 겹쳐 보일 수 있으며 이는 버그가 아니다

5

가게 홍보 '지금 가장 핫한 가게'

- 가게 3개를 좌우 스크롤로 노출, 가게당 종목 최대 2개를 하위 목록으로 표시(서버 노출 순서) - 대형 이미지 카드: 가게명, 대표 문구, '혜택' 배지, 혜택 설명 문구, 우측 상단 스크랩(북마크) 아이콘 - 하위 종목 행: 종목명·현재가·등락률·[주문]·찜(♡, 비로그인이라 빈 하트) -> [주문] 클릭시 해당 종목의 상세> 주문 페이지로 이동 (동일함) - 카드/종목 탭 → 각각 가게 상세/종목 상세로 이동

6

신규 종목 '새로 올라왔어요'

- 최근 상장순 3개, 세로 목록. 상장 종목만 조회 - 각 행: 가게명·종목명·현재가·등락률·[주문]·찜(♡, 비로그인이라 빈 하트) - 헤더 우측 [더보기] → 거래 목록이 '최근 상장순' 필터링된 상태로 '거래> 전체' 목록으로 이동

7

이벤트·혜택

- 서버 노출 순서로 최대 5개, 좌우 스크롤(자동 넘김 없음 — 손으로 밀어야 함) - 노출 중인 이벤트가 0건이면 섹션 자체가 사라짐 - 카드 영역 카드 탭 → 이벤트 상세로 이동

8

지역 카드 — '내 주변 픽'

- 등록된 지역 수만큼 칩 노출(서울·경기·인천·강원·대전 등) 되며, 백년가게 > 내 주변(전체) / 지역 칩 탭 → 백년가게 > 내 주변(해당 지역 지정)

9

백년라운지

- 가게 3개, 가게당 최신 글 3개(최신순) — 라운지 글이 0건이면 섹션 전체가 사라짐 - 카드 구성: 가게명(고요한상 등)·최신 글 미리보기·[더보기] - [더보기] 버튼 클릭-> 백년가게> 가게상세> 커뮤니티 목록 이동 - 글 미리보기 탭 → 그 종목의 커뮤니티로 이동 / 가게명 탭 → 그 가게 상세의 커뮤니티 탭으로 이동(서로 다른 목적지이므로 구분 필요)

10

공지 띠 + 푸터

- 공지 띠: 최신 공지 1건만 노출(예: '[공지][필수] 투자자 성향 분석 필수 안내'), 공지가 0건이면 섹션이 사라짐 — 탭 시 공지 상세로 이동 - 하단 푸터: 서비스 고지 문구('정보는 투자 참고용이며 실제와 차이가 있을 수 있고, 투자 결과의 법적 책임은 사용자에게 귀속'), [투자자 유의안내]·[개인정보처리방침]·[고객센터] 링크
